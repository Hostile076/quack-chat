## 本轮发现并修复的 Bug

1. **管理员权限没有真正生效**：邀请、踢人、发公告、精华仍调用 `requireOwner`，管理员会收到 403。已改为 `requireManager`。
2. **管理员可以踢群主**（接口层）：已增加群主保护，返回 400「不能移出群主」。
3. **加群提交申请后「待处理」角标不更新**：`requestJoinGroup` 成功后没有刷新角标。已增加 `refreshGroupJoinBadge()`。
4. **编辑空间动态后好友端不刷新**：`moment.edit` 只推给作者本人。已改为推给作者 + 好友（PRIVATE 只推自己）。
5. **群解散后查详情返回 403**：先判断成员关系再做存在性判断。已改为先查群存在（404），再查成员（403）。
6. 此前用户指出的**群公告/群管理「+」空白**：复用带 28px 横向 padding 的按钮样式导致加号被裁掉，已改为专用圆形按钮样式。
7. 此前**退群后本地僵尸会话**：已补本地库会话/消息/草稿/已读清理与本人 `group.removed` 推送。
8. 此前**加好友备注位置**：已从搜索页移到「确认添加好友」弹窗。
